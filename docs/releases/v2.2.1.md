# v2.2.1

## 优化

| 项目 | 改进 |
| --- | --- |
| 多账号 | 手动核对所选账号；慢账号不会挡住其他账号当轮提醒；总览减少重复会话检查 |
| 账号名称 | 重名邮箱和昵称自动区分，管理页与各渠道提醒使用一致名称 |
| 登录 | 阻止并发授权和取消后的旧回调；保存会话成功后才登记账号 |
| 提醒 | 发送前复查延期、免打扰、开关和去重条件 |
| 立即重置 | 区分未发起请求与结果待确认，保留幂等和二次确认 |
| Windows 更新 | 重查、离线检查和安装器启动失败后仍可升级或重试 |
| 界面 | 保存期间锁定账号输入；登录失效与提醒暂停按真实状态显示 |

## 验证与范围

- 使用隔离数据库、账号和模拟接口；未消费真实卡、发送测试飞书消息。
- Windows 安装包与三平台 CI 检查；详细范围见[验收记录](https://github.com/Adgai115/codex-reset-reminder/blob/main/docs/reliability-acceptance-2026-09-30.md)。
- Windows 未签名；macOS 未签名、未公证。Linux 独立账号需解锁的系统密钥服务。
