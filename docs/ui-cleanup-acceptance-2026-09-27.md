移除常驻工作原理、页脚说明和重复提示。正常状态使用次要颜色，临近到期、账号异常、提醒关闭和操作失败仍有明确提示。成功提示六秒后自动收起；完整错误信息可展开。测试弹窗保留“测试”标题，正式用卡及旧缓存绑定的确认边界保留。

延期选择即生效，管理页和提醒弹窗使用相同操作方式。提醒弹窗的延期失败仍保留窗口和错误，选择成功后保存并关闭。已有自动同步、有限补发、账号保护、免打扰与去重逻辑不变。
