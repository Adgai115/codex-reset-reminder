# v2.2.0

## 多账号管理

- 新增账号列表与官方浏览器登录，每个账号保存独立会话。
- 选择账号后显示对应卡片、同步记录与提醒记录，缓存立即可读。
- 已登录账号分别在后台同步和提醒；切换界面或 CLI 账号不会停止其他账号。
- 单账号失败独立重试，支持账号名称和单账号提醒开关。
- 相同官方卡号按账号隔离；桌面和飞书正式用卡使用卡片所属账号，保留二次确认。
- 旧卡片、延期与发送记录保留。升级前的历史账号需独立登录一次，随后可在后台运行。

## 凭据与验证

- 登录会话通过系统密钥加密保存；不写入配置、界面或日志。
- 测试使用隔离账号与模拟接口，覆盖账号切换、故障隔离、重复卡号、凭据保护和重启恢复。
- Windows 本机安装包与三平台 CI 验证；macOS/Linux 托盘、自启、休眠仍未实机验收。
- Windows 安装包未签名，macOS 未签名、未公证。Linux 多账号独立会话需要解锁的系统密钥服务，禁用不安全的 `basic_text` 回退。
