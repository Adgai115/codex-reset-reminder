# v2.3.0

开发候选版本，当前未发布；本机正式安装仍为 v2.2.3。

## 个人微信提醒

| 功能 | 行为 |
| --- | --- |
| 微信（PushPlus） | “设置 → 提醒”配置个人用户 Token，经 PushPlus 公众号接收到期通知 |
| 多账号 | 接收人全局共享，每条通知明确所属账号、卡片和到期时间；各账号记录分别保留 |
| 安全存储 | Token 使用系统密钥加密，不进入普通配置、日志或数据库；再次打开留空保留 |
| 显式测试 | 保存配置后点击“发送微信测试”才提交一条演示通知，保存和打开设置不会自动发送测试消息；启用后正常提醒可立即补查 |
| 发送结果 | 官方接口接收请求显示“微信已提交”；结果不明确显示“结果待核实”，不宣称微信已送达 |
| 去重与补发 | 已提交或结果待核实的节点不重复发送；明确失败使用既有有限补发规则，账号受限时停止自动补发 |
| 正式用卡 | 微信仅通知，正式重置继续由用户在桌面应用核对账号与卡片并二次确认 |

旧公众号配置继续保留；填写并保存 PushPlus Token 后可切换到新渠道。保留桌面、飞书、完整多账号管理和统一设置体验。

配置步骤见[桌面版使用指南](../user-guide.md#微信pushplus)，验证范围见[PushPlus 验收记录](../pushplus-acceptance-2026-10-02.md)。微信服务方的实名认证和额度要求以 [PushPlus 官方说明](https://www.pushplus.plus/doc/guide/use.html)为准。

## 验证与范围

- 自动验证使用隔离数据、模拟账号、模拟 HTTP 与安全存储，不消费真实卡、不发送真实飞书或微信、不修改正式配置。
- 当前真实微信送达尚未验收，需用户配置自己的 Token 后显式发送测试，并在手机确认接收。
- 本地 140 项测试通过、1 项平台条件跳过；Windows 构建、包内容、更新附件、普通及多账号安装包烟测通过。本文件不代表 GitHub CI 或发布已完成。
- 本候选版 Windows 安装器实际状态为 `NotSigned`；当前没有 Windows 证书或 Apple Developer ID，缺少签名材料不阻断发布。macOS/Linux 真实桌面的托盘、自启和休眠恢复仍需实机验收。
