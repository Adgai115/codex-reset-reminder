# v2.2.2

## 界面优化

| 页面 | 改进 |
| --- | --- |
| 重置卡管理 | 页头更紧凑；800px 窗口无需横向滚动；状态与到期时间合并显示 |
| 卡片与记录 | 渠道结果保持单行；完整信息与失败原因可打开详情，支持键盘操作 |
| 多账号 | 账号管理中“查看”直接进入对应列表；操作结果在当前弹窗显示 |
| 提醒设置 | 通知与免打扰对齐，保存区固定，详细配置按需展开 |
| 安装与提醒 | 统一配色、深色模式与控件；提醒保留紧凑单卡和二次确认 |
