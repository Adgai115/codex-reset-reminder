# Codex 重置卡到期提醒 2.0.3

Windows 安装版现在可在“提醒设置 → 关于”检查新版本、下载并校验更新，然后确认在原安装位置升级。升级后自动重新打开应用；配置和卡片数据库保存在用户数据目录。下载失败可重试或打开本仓库发布页。更新不会在正常退出时自行安装。

**从 2.0.2 或更早版本升级到 2.0.3，仍需手动运行一次本版安装包。** 这些旧版尚未包含应用内下载功能。从 2.0.3 开始，后续发布可走应用内升级。

Windows 安装包和 `latest.yml` 使用相同版本及文件名，发布前校验 SHA-512。安装包目前未签名，Windows 可能显示安全警告。macOS 和 Linux 保持从发布页安装对应包；macOS、Linux 的真实托盘、自启、休眠恢复和升级仍需实机验收。
