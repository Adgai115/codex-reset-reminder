# 统一设置验收

版本：2.2.3。沿用原有界面风格，将账号操作与提醒配置合并到同一设置窗口。

## 改动

| 位置 | 结果 |
| --- | --- |
| 管理页 | 同步时间、连接状态直接显示；账号选择框仅显示名称，移除管理选项和“当前”后缀 |
| 设置入口 | 管理页与托盘统一为“设置”，提供“提醒 / 账号”两个页签 |
| 账号页 | 添加、登录、名称、提醒开关、查看、核对和旧缓存确认集中管理 |
| 保存与返回 | 账号偏好即时保存；提醒草稿跨页签保留。“查看”收起设置并显示对应卡片，再打开保留草稿 |
| 关闭保护 | 保存、登录启动或核对时阻止关闭；正在编辑的账号名称也进入未保存保护 |
| 操作提示 | 登录、旧缓存绑定与渠道故障提示均指向新设置入口 |

设置页只能请求账号管理所需操作。安装包测试确认设置页不能延期、补发提醒、调用正式重置、重新打开提醒或退出应用。

实际 Chromium 渲染检查覆盖：管理页 1180px / 800px，设置页 660×700 / 560×500，浅色和深色。状态与常用按钮保持单行，无横向滚动。另检查名称编辑期间后台刷新、保存失败回滚、读取期间状态变化、空账号与登录取消；均通过。

旧缓存确认使用模拟候选账号验证：取消不请求绑定，确认准确发送快照的候选令牌；完整同步、详情不全和同步失败分别显示真实结果与原因。核心测试继续验证候选账号变化时拒绝绑定。

界面截图与模拟测试输出存于本机 `.git/` 下，不进入发行包或仓库根目录。三平台自动验证结果见仓库 Actions。
