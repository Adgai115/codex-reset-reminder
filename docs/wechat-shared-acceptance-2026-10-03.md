# 本机微信共用通知验收（2026-10-03）

## 范围

在独立微信直连工具中增加可手动启停的本机网关，提供每来源的加密权限文件、撤销、通知编号去重、单进程微信发送及公开结果。Node 调用脚本接受 UTF-8 stdin；旧 PowerShell 5 示例使用字节流输入。开发版提醒应用通过统一“设置 → 提醒”选择实验网关，继续保留多账号、固定和延期提醒、旧渠道配置与简洁界面。

该能力未发布、未安装到正式 v2.2.3，不改变正式配置、数据库或其他 agent 配置。网关默认关闭，重启不自动启用，不恢复定时测试。本阶段只实现通知，共用微信对话的路由尚未实现。

所有自动化发送只使用模拟微信客户端、本机回环 HTTP 和隔离文件。没有测试飞书、真实卡片消费或正式配置修改。本轮未通过共用接口发送新的真实微信测试消息。

Windows Electron 的继承 stdin 未可靠收到内容，已改为一次性鉴权回环桥；消息不进进程参数和日志。Windows `safeStorage` 跨 profile 解密需要原 profile 的 DPAPI 密钥封装，导出仅包含该 OS 保护的封装和加密调用凭据，帮助进程用自己的临时 Local State，不修改网关或正式应用的 profile。系统加密不可用、`basic_text`、导出失败、存储失败等情形拒绝执行。
