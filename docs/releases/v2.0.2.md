# Codex 重置卡到期提醒 2.0.2

修正 Windows 安装器创建的快捷方式名称。桌面和开始菜单统一使用“Codex 重置卡提醒”；从英文名称升级时，安装器会处理旧入口，避免出现中英文两个启动图标。应用功能与 2.0.1 相同。

Windows 本机从 2.0.1 升级到 2.0.2 的安装退出码为 0。桌面和开始菜单均只保留中文快捷方式，两个入口都指向已安装的 2.0.2。测试没有启动正式提醒程序。本机安装包 SHA256：`524F070D264B1E4593244C2A752711D1070941DE65D4CA2FDA84FB21C10F8A16`。

下载对应平台的安装包，并用 `SHA256SUMS.txt` 校验。Windows 安装包未签名；macOS 安装包未签名、未公证。三平台 CI 使用隔离数据与模拟 Codex 依赖验证构建和桌面流程；macOS、Linux 的真实托盘、自启、休眠恢复及升级仍需实机验收。
