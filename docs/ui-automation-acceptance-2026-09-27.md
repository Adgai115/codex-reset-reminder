# 界面与自动化验收（2.0.0-beta.3）

## 本轮变化

- 默认窗口扩大到 1180 × 680；名称、时间、状态和操作保持单行，长名称省略显示。800 像素窗口只在表格内部横向滚动。
- 卡号显示尾部便于区分同名卡，完整编号、名称、到期时间和全部发送节点可展开读取；发送失败原因有完整文本，刷新保留展开状态。
- 主列表显示最近节点各渠道的状态、时间、失败原因和自动补发时间；保留“重试失败渠道”入口与尝试上限。
- 延期改为菜单直接选择，取消延期也在同一菜单；可选的使用反馈收在“更多”，不要求日常每次手动报告。
- 启动同步，之后每 15 分钟刷新；失败或不完整响应按 1、5、15 分钟重试，持续失败保持十五分钟间隔，成功重置。唤醒自动核对，多个在途请求合并。
- 自动核对由后台调度器执行，不依赖管理页可见性。恢复后自动更新列表；账号不一致仍暂停同步与提醒，首次旧缓存绑定和正式用卡仍需要确认。
