# v2.2.3

## 统一设置

| 页面 | 改进 |
| --- | --- |
| 重置卡管理 | 同步与连接状态直接显示，去除折叠箭头；左上角只显示账号名称，完整信息通过悬停提示和记录查看 |
| 设置入口 | 管理页与托盘统一为“设置”，账号选择框只用于切换查看 |
| 提醒 | 保留原有分组和保存方式；切换到账号页后，未保存配置继续保留 |
| 账号 | 集中添加、命名、登录、查看和核对；名称及提醒开关即时保存，“查看”切换对应卡片与记录 |

## 验证与范围

- 验证使用隔离数据、模拟账号和渠道，不消费真实重置卡、不发送测试飞书消息。
- 验收范围包括窄窗口布局、直接显示的状态、多账号切换、重新核对、登录恢复、旧缓存确认和未保存提醒配置。
- Windows 安装包与原生窗口交互验证通过；参见[验收记录](https://github.com/Adgai115/codex-reset-reminder/blob/main/docs/ui-settings-acceptance-2026-10-02.md)。
- Windows 保持原安装位置升级，用户配置、账号和记录保存在独立数据目录。
- Windows 未签名；macOS 未签名、未公证。macOS/Linux 真实桌面的托盘、自启和休眠恢复仍需实机验收。
