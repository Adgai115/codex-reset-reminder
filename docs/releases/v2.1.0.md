# Codex 重置卡到期提醒 2.1.0

## 多账号

- 切换本机 Codex CLI 登录账号后，应用自动识别并同步当前账号的官方重置卡；切回旧账号即恢复原卡片、延期和提醒记录。
- 管理页、同步数量与时间、待处理提醒和补发按账号隔离。正式用卡前仍核对当前账号及卡片归属。
- 从 2.0.3 升级时保留原数据库。已有卡片首次绑定仍需确认原账号；无法识别账号时暂停同步、提醒与正式用卡。

## 升级与验证

Windows 2.0.3 用户可在“提醒设置 → 关于”检查并安装本次更新。升级会保留用户数据目录中的配置和卡片数据库。三平台 CI 使用隔离数据与模拟 Codex 验证数据库迁移、账号切换和安装包流程；未消耗真实重置卡，也未发送真实飞书消息。

Windows 安装包未签名，可能显示系统安全警告。macOS 包未签名、未公证。macOS 和 Linux 的真实托盘、自启、休眠恢复及升级仍需实机验收。发布附件提供 SHA256 校验文件和 GitHub 构建来源证明；来源证明不等于操作系统代码签名。
