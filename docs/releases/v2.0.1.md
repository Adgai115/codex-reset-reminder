# Codex 重置卡到期提醒 2.0.1

本版优化提醒和卡片管理，并修正 Codex 连接诊断的状态说明。

## 变化

- 桌面提醒显示当前已核对账号、卡名和编号尾号。同轮多卡在一个无滚动条窗口内切换，逐卡延期。
- 桌面与新飞书提醒统一使用“立即重置”。桌面先显示账号与卡片的二次确认；取消不会请求用卡。请求结果不明确时，重启后复用同一幂等标识，避免生成另一笔请求。测试提醒不能用卡。
- 管理页移除手动报告使用，给同名卡显示编号尾号；筛选改为“可用卡 / 已提醒 / 已结束”。“重新核对账号”会同时刷新卡片，并按实际结果提示。
- Codex 只返回可用数量但未提供逐卡到期详情时，连接诊断会明确说明。已有缓存保留并自动重试，不推断缺失卡片的到期时间。

## 验证范围

自动化测试使用隔离 SQLite 和模拟 Codex、飞书依赖，不发送真实消息、不使用真实重置卡。Windows 安装包完成本地内容、界面、提醒流程和原位安装检查；三平台 CI 构建和模拟界面检查以工作流结果为准。macOS、Linux 的真实托盘、自启、休眠恢复及升级仍需实机验收。Windows 和 macOS 安装包未签名，macOS 未公证。

Codex App Server 协议允许 `credits` 为 `null`，也允许详情数小于 `availableCount`。此时应用无法得知每张卡的编号或到期时间，详见[官方响应结构](https://github.com/openai/codex/blob/main/codex-rs/app-server-protocol/schema/json/v2/GetAccountRateLimitsResponse.json)。
