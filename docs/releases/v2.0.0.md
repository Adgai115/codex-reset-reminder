# Codex 重置卡到期提醒 2.0.0

首个正式跨平台桌面版本。支持 Windows、macOS 和 Linux，通过已登录的 Codex CLI 读取官方发放的重置卡，在到期前 7、3、1 天提醒。

## 主要功能

- 自动同步官方卡片；列表按到期时间展示可用卡、历史卡与待处理提醒。卡片名称和到期时间不能在应用中新增或编辑。
- 桌面弹窗可合并同轮多张卡，并能在关闭或重启后重新查看待处理卡；重新查看不会重发消息。
- 按卡片和渠道显示提醒发送结果。失败渠道最多补发三次，按 1、5、15 分钟退避，并遵守延期、免打扰、渠道开关和账号核对规则。
- CLI 换号或账号无法核实时暂停同步、提醒和正式用卡，防止不同账号的缓存混合。旧缓存首次绑定需要确认原账号。
- 保留 Windows 旧版数据迁移、SQLite/Node sidecar 兼容模式，以及桌面弹窗和可选飞书提醒。

## 下载与校验

按操作系统下载 Windows NSIS 安装程序、macOS DMG、Linux AppImage 或 deb。`SHA256SUMS.txt` 包含各安装包的 SHA256 校验值。升级前请退出旧版并备份用户数据；使用方法见[桌面版使用指南](https://github.com/Adgai115/codex-reset-reminder/blob/main/docs/user-guide.md)，本机验证见[正式版验收记录](https://github.com/Adgai115/codex-reset-reminder/blob/main/docs/stable-release-acceptance-2026-09-28.md)。

## 验证范围与限制

三平台 CI 使用隔离数据和模拟 Codex 依赖完成单元测试、SQLite 探针、安装包检查，以及安装、界面、提醒补发、后台恢复和待处理流程测试。Windows 已在本机验证安装与快捷方式。macOS、Linux 的真实桌面托盘、自启、休眠恢复及升级仍需实机验收；真实飞书超时后的服务端幂等效果也未实测。

Windows 安装包未签名；macOS DMG 未签名、未公证，安装时可能需要手动允许。应用不会自动消费重置卡，也不会自动下载或安装更新。
